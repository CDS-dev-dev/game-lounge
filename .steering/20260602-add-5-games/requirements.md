# 5ゲーム追加 - 要求仕様書

## 概要

Game Loungeプラットフォームに以下の5つのゲームを追加する。既存ゲーム（ガイスター、立体四目並べ、中国象棋）と同等以上の品質で実装する。

## 追加するゲーム

### 1. インディアンポーカー
- **ジャンル**: 心理戦カードゲーム
- **プレイ人数**: 2-10人
- **特徴**: 自分のカードが見えない、相手の反応で予想
- **目標プレイ時間**: 5-10分/ゲーム

### 2. ドラゴンタイガー
- **ジャンル**: カジノゲーム（バカラ簡易版）
- **プレイ人数**: 2人以上
- **特徴**: ドラゴンvsタイガー、どちらが強いカードか予想
- **目標プレイ時間**: 1-3分/ラウンド

### 3. エンペラーゲーム（カイジ）
- **ジャンル**: 階級制心理戦ゲーム
- **プレイ人数**: 3-6人推奨
- **特徴**: 皇帝・市民・奴隷の階級でコインを奪い合う
- **目標プレイ時間**: 20-30分/ゲーム

### 4. テキサスホールデム
- **ジャンル**: ポーカー
- **プレイ人数**: 2-9人
- **特徴**: 世界で最も人気のポーカー、戦略性が高い
- **目標プレイ時間**: 30-60分/ゲーム

### 5. アイランドセトラーズ（カタン風オリジナルゲーム）
- **ジャンル**: 開拓・資源管理ゲーム
- **プレイ人数**: 3-4人
- **特徴**: 資源を集めて島を開拓、交渉要素あり
- **目標プレイ時間**: 60-90分/ゲーム
- **注意**: カタンの著作権を侵害しないオリジナル実装

## 品質要件

### 機能要件
1. **既存ゲームと同等の機能**
   - オンライン対戦（自動マッチング）
   - ローカル対戦（同一端末）
   - CPU対戦（AI実装）
   - ルール説明ページ

2. **多人数対応の特別機能**
   - プレイ人数選択機能
   - オンラインマッチング待ち時に「残りCPU」選択可能
   - 全員がCPU許可したら即開始

3. **ゲームプレイ機能**
   - リアルタイム対戦
   - 待った機能（ローカル・CPU戦のみ）
   - 履歴表示
   - キーボード/タッチ操作対応

### 非機能要件
1. **UIデザイン**
   - 縦スクロール不要（全画面）
   - スマホ・PC両対応
   - レスポンシブデザイン
   - 既存ゲームと統一感のあるデザイン

2. **パフォーマンス**
   - 操作の即座のフィードバック
   - リアルタイム対戦のレスポンス速度
   - 大人数対応（最大10人）

3. **コード品質**
   - TypeScript型安全性
   - テストカバレッジ
   - エラーハンドリング
   - アクセシビリティ対応

4. **SEO対応**
   - 各ゲームページの構造化データ
   - メタタグ最適化

## 実装制約

### 技術スタック
- Next.js 15（App Router）
- TypeScript
- Tailwind CSS
- Prisma（データベース）
- 既存のコンポーネントライブラリを活用

### 著作権対応
- カタン：完全オリジナル実装、名前・ルールを変更
- エンペラーゲーム：ルールは公開情報、名前は一般名詞化
- その他：パブリックドメインまたは一般的ルール

### コード規約
- 既存コードとの一貫性
- docs/5_development-guidelines.mdに従う
- 日本語コメント
- エラーハンドリング必須

## 成功基準

1. **機能完全性**: 全ゲームが仕様通り動作
2. **品質**: 既存3ゲームと同等以上のコード品質
3. **UX**: 縦スクロール不要、快適な操作性
4. **テスト**: 主要機能のテスト実装
5. **デプロイ**: Vercel本番環境で正常動作

## スコープ外

- モバイルアプリ化
- 課金機能
- ランキング・実績システム
- チャット機能
- 音声通話
