# タイガー＆ドラゴン（牌ゲーム）- 要求仕様

## ゲーム概要

アークライト×オインクゲームズのボードゲーム「タイガー＆ドラゴン」。
ごいた系の牌ゲームで、攻めと受けを繰り返して手牌を出し切るゲーム。

## 基本ルール

### プレイ人数
- 2-5人

### 牌の構成
- 数字牌：1-8（各5枚ずつ、計40枚）
- 奥義牌：タイガー奥義（1枚）、ドラゴン奥義（1枚）
- **合計42枚**

### ゲームの流れ

1. **準備**
   - 各プレイヤーに牌を配る
     - 2人：各20枚
     - 3人：各13枚
     - 4人：各10枚
     - 5人：各8枚
   - スタートプレイヤーは+1枚
   - 戦場カード（得点ルール）を1枚選ぶ

2. **攻めと受け**
   - スタートプレイヤーが牌を1枚「攻め」で出す
   - 左隣のプレイヤーから順に「受け」を試みる
   - 同じ数字の牌があれば「受け」られる
   - 受けたプレイヤーが次の「攻め」を行う
   - 受けられない（or受けたくない）場合はパス

3. **奥義牌**
   - **タイガー奥義**
     - 受けで使う：偶数（2,4,6,8）を全て受けられる
     - 攻めで使う：偶数の牌で受けられてしまう
   - **ドラゴン奥義**
     - 受けで使う：奇数（1,3,5,7）を全て受けられる
     - 攻めで使う：奇数の牌で受けられてしまう

4. **1周ボーナス**
   - 攻め牌が全員にパスされて自分に戻ってきた場合
   - 好きな手牌を1枚裏向きで出せる（受け列に配置）
   - 上がり時に1周ボーナス数×1枚の得点チップ追加

5. **上がり**
   - 手牌が0枚になったプレイヤーが「上がり」
   - 最後に出した牌（上がり牌）に応じて得点チップ獲得
   - 1周ボーナス分の追加得点

6. **勝利条件**
   - 得点チップを10枚集めたプレイヤーが総合優勝

### 戦場カード（得点ルール）

全6種類：

1. **偶数（2,4,6,8）で上がり → 2点**
2. **奇数（1,3,5,7）で上がり → 2点**
3. **小さい数（1,2,3,4）で上がり → 2点**
4. **大きい数（5,6,7,8）で上がり → 2点**
5. **奥義（タイガー/ドラゴン）で上がり → 3点**
6. **何で上がっても → 1点**

### チーム戦（4人用）
- 2人ずつのチーム
- チームで15枚集めたら勝利
- 向かい合って座る

## 実装要件

### 必須機能
1. 2-5人対応
2. 攻め・受けシステム
3. 奥義牌の特殊ルール
4. 1周ボーナス
5. 戦場カード（得点ルール）
6. 複数ラウンド（10点まで）
7. AI実装（手牌推測、受け判断）
8. ローカル対戦
9. CPU対戦

### UI要件
- 縦スクロール不要
- 牌の表示（数字、奥義）
- 攻め列・受け列の表示
- 手牌表示
- 得点チップ表示
- 戦場カード表示
- 1周ボーナスカウンター

## 実装しないもの
- オンライン対戦（準備中表示のみ）
- チーム戦（今回は個人戦のみ）
